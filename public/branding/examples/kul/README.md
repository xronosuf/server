# KU Leuven branding example

This directory preserves branding assets from a KU Leuven Ximera/Xronos
deployment as a reference for institutions adapting Xronos.

These files are examples, not part of the active UF deployment, and application
runtime code should not depend on them.

KU Leuven-related compatibility behavior elsewhere in Xronos is not necessarily
branding and is intentionally outside this example directory.
